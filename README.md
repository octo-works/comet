# Comet
Small and fast without sacrificing function. The OS shouldn't get in the way, but running a raw shell is not enough for a daily driver. This project hopes to answer that question.

> [!NOTE]
> I love dynamic tiling window managers, yet running them on my X1 Carbon Gen 5 started to get sluggish. Hence this project was born from that need.



## Goals:
- ArchLinux, because living on the edge is best
- Razor thin dependencies
- Absolute lightest on RAM and GPU
- With all the daily driver needs:
    - app launcher
    - media controls
    - user friendly setting controls
    - a nice fast shell
    - date/time and status

## Derivative work
Comet borrows ideas from the leading platforms and tools to keep the experience fresh and fast.
